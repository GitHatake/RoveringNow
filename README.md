# RoveringNow

> 連絡が届き、活動が記録され、仲間が集まる
> — ローバースカウトのためのデジタル手帳

日本のボーイスカウト運動における「ローバースカウト」世代（18〜26歳）を対象とした、SNS型のWEBアプリケーションです。

設計は [`docs/`](docs/) にあります。開発は**設計書が主導**し、実装と食い違ったときは設計書を先に改訂します。

## 動作確認のしかた

**外部サービスの登録は不要です。** データベースは PGlite（WebAssembly 版 PostgreSQL）としてローカルのファイル上で動きます。

```bash
npm install
npm run db:generate   # マイグレーションを生成（初回のみ）
npm run db:seed       # 動作確認用のデータを投入
npm run dev           # http://localhost:3000
```

`.env.local` に次を書くと、**認証を省いて画面を確認できます**。

```
AUTH_MODE=dev
```

このとき画面上部に赤いバーが出て、利用者を切り替えられます。**これは認証ではありません。**誰でも任意の利用者になりすませるため、動作確認以外では使わないでください。

### 見どころ

| 画面 | 確認できること |
|---|---|
| ホーム | **配下配信**。「海野 千尋」は団の隊員だが、連絡会・協議会の連絡も届く |
| ホーム | **参加意向の可視化**。誰が「参加したい」を押したかが見える |
| 連絡を書く（梶 亮太） | **配信対象人数の常時表示**。範囲を切り替えると人数が変わる。配下配信のみ確認を挟む |
| グループを作る | **名前の重複判定と代替名の提案**。`すみだローバースカウト協議会` と入力すると候補が出る |
| グループ詳細（梶 亮太） | **配下ツリー**。孫以降まで一覧できる／参加申請の承認 |
| コレクション | 実用の層と違い、**紙の地と箔押し風の縁**を使う領域 |

### データを作り直す

```bash
npm run db:reset      # .data/ を消して投入し直す
```

## 開発

```bash
npm run verify        # lint → 型検査 → テスト（270件）
npm run test          # テストのみ
npm run db:generate   # スキーマ変更後にマイグレーションを生成
```

テストは PGlite 上で**実物の PostgreSQL** に対して実行します。外部サービスへの接続は不要です。

| テスト | 内容 |
|---|---|
| `tests/authorization.test.ts` | 権限マトリクス 35行 × 5ロール ＝ 175通りの総当たり |
| `tests/group-name.test.ts` | 名前の正規化。ゼロ幅スペース等による偽装の検出 |
| `tests/db-constraints.test.ts` | アプリを介さず直接SQLで制約を破ろうとする |
| `tests/broadcast.test.ts` | 配下配信の再帰クエリ。切断・アーカイブ・循環耐性 |

## 本番構成への切り替え

`.env` に `DATABASE_URL` を設定すると PostgreSQL（Supabase）へ接続します。データベースの選択はコードを変えずに切り替わります。

認証は `src/lib/session.ts` の `getActor()` のみが担っているため、認証基盤を差し込む際に変更が必要なのはこのファイルだけです。アプリ内のユーザー識別子は自前の `users` テーブルで持っています。
